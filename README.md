# Telegram-бот для подбора мебели
Кейс Т-банка на хакатоне IT Purple Hack

Telegram-бот, способный подбирать мебель под заданные параметры - размер комнаты, бюджет, пожелания по стилю и так далее.
Имеет доступ к базе данных с мебелью, которую он может предлагать пользователю, основываясь на параметрах этой мебели и ее совпадению с желаниями пользователя.
Бот способен формировать корзину покупок для пользователя. У пользователя есть возможность управлять предметами в корзине (добавлять, удалять).
